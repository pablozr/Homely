# 01 - Fundacao backend e mobile

**What to build:** estabelecer o projeto Expo mobile e o contrato de desenvolvimento local com a API existente, para que o app possa abrir e chamar a API local.

**Blocked by:** 00 - Configuracao dos ambientes.

**Status:** completed

- [x] O repositorio possui `mobile/` Expo/TypeScript com Expo Router e integracao com as configuracoes de ambiente existentes.
- [x] O mobile possui cliente HTTP fino, base URL por ambiente, TanStack Query, estrutura por feature e tipos gerados do OpenAPI.
- [x] Lint, typecheck e testes basicos executam no mobile; compilacao e testes basicos executam no backend; CI detecta tipos OpenAPI desatualizados.
