# 01 - Fundacao backend e mobile

**What to build:** estabelecer o projeto Expo mobile, configuracao por ambiente e o contrato de desenvolvimento com a API existente, para que o app possa abrir e chamar um endpoint autenticavel de preview/local.

**Blocked by:** 00 - Configuracao dos ambientes.

**Status:** ready-for-agent

- [ ] O repositorio possui `mobile/` Expo/TypeScript com Expo Router e integracao com as configuracoes de ambiente existentes.
- [ ] O mobile possui cliente HTTP fino, base URL por ambiente, TanStack Query, estrutura por feature e tipos gerados do OpenAPI.
- [ ] Lint, typecheck e testes basicos executam nos dois projetos; CI detecta tipos OpenAPI desatualizados.
